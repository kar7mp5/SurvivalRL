# SurvivalRL

## Overview

SurvivalRL is a simulation project that models an evolving ecosystem using Reinforcement Learning (RL) and Genetic Algorithms (GA). The goal is to create an environment where agents learn to survive, adapt, and evolve over time by interacting with their surroundings.

-   Reinforcement Learning (RL): Agents learn optimal behaviors by trial and error, receiving rewards based on their survival and interactions.
-   Genetic Algorithm (GA): Evolutionary strategies such as mutation and crossover help improve agent performance over multiple generations.
    This project runs on WSL-Ubuntu 22.04 and requires Python 3.10.12.

## Getting Started

This project is based on `WSL-Ubuntu22.04` and `Python3.10.12`.

### Install libraries

Before running the simulation, install the required dependencies:

```sh
$ pip3 install -r requirements.txt
$ sudo apt-get install python3-tk
```

### Run the simulation

To start the simulation, execute the following command:

```sh
$ python3 main.py
```
